🧾 Family Receipt Manager & Expense Categorizer
A responsive React web application designed for family receipt management, expense categorisation, OCR scan simulation, and Excel export (.xlsx).
🌟 Key Features
📸 Mobile Camera Capture & File Upload: Instant receipt scanning directly using your phone's camera or image gallery.
👨‍👩‍👧‍👦 Family Member Categorization: Track spending by family member (Dad, Mom, Kids) with custom badges and filter analytics.
🏷️ Smart Category Management: Group expenses into categories (Supermarket, Fuel, Dining, Pharmacy, Utilities, etc.) with real-time budget cards.
📊 Real-Time Analytics: Summary totals and metrics for family budgeting.
📥 Excel (.xlsx) Multi-Sheet Export: One-click generation of formatted Excel spreadsheets:
Sheet 1: All Receipts Breakdown
Sheet 2: Category Spending Summaries
Sheet 3: Per-Member Spending Summaries
📲 Mobile Web App Ready: Installable on iOS (Safari) and Android (Chrome) via "Add to Home Screen".
🚀 Getting Started
Prerequisites
Make sure you have Node.js installed on your computer.
Installation
Clone the repository:
```bash
   git clone https://github.com/YOUR_USERNAME/family-receipts.git
   cd family-receipts
   ```
Install dependencies:
```bash
   npm install
   ```
Run the development server:
```bash
   npm run dev
   ```
🌐 Deploy to Netlify / Vercel
This project is ready to deploy on Netlify or Vercel:
Connect your GitHub repository to Netlify/Vercel.
Build command: `npm run build`
Publish directory: `dist` or `build`
